# PanglaoDB: a web server for exploration of mouse and human single-cell RNA sequencing data

## Key findings

- PanglaoDB converted public human and mouse scRNA-seq deposits into a searchable, protocol-agnostic resource with unified preprocessing and precomputed analyses.
- At publication it covered more than 1,054 experiments and four million cells across major platforms and tissues.
- A community-curated marker compendium contained more than 6,000 gene–cell-type associations for annotation and exploration.
- The central contribution is accessibility and reuse: raw archival submissions become comparable reference material for researchers without rebuilding every pipeline.

## Limitations

- Unified processing improves comparability but cannot remove source-study quality, metadata, protocol, and sampling differences.
- Marker compendia can encode literature bias and should support, not replace, dataset-specific validation.
